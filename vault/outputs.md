# 主定理与推论：结论的范围与量词

本模块梳理主算法的推论，重点区分各结论所需的算法保证、指数参数与量词。

## 主结论的两个入口

[[1.1|定理 1.1]] 是固定 $k$ 的精确 #k-SAT 计数、确定性时间与多项式空间保证。一般密度指数为 $O_k(n\log\log n/\sqrt{\log n})$，固定子句密度为 $O_{k,D}(n/\sqrt{\log n})$。强界来自 [[route-b|路线B]]：固定密度由 [[D.1|定理 D.1]] 直接接入；一般密度由 [[D.2|引理 D.2]] 与 [[shared-sat|共享SAT工具]] 组合。[[6.4|命题 6.4]] 给出路线 A 的较弱上界。

## 输出地图

| 节点 | 使用主定理的哪一部分 | 精确范围 |
| --- | --- | --- |
| [[1.2|推论 1.2：Max-k-SAT]] | 只需判定满足性；另有随机抽样 | 加法误差 $\varepsilon m$，成功概率 $1-2^{-\Omega(n)}$；原文时间界采用较弱 $\rho(n)$ |
| [[1.3|推论 1.3：图计数]] | 精确计数与保持计数的编码 | 独立集、固定色数着色为 $2^{o(v)}$；完美匹配为 $2^{o(v+e)}$ |
| [[C.2|推论 C.2：局部映射]] | 精确计数及逐变量自归约 | 固定输出局部度；原像计数和求一个原像；原文时间采用 $\rho(n)$ |
| [[C.1|推论 C.1：定性电路下界]] | 次指数3-SAT判定 | $\mathrm E^{\mathrm{NP}}\not\subseteq\mathrm{SIZE}(O(n))$；还调用 Williams 外部定理 |
| [[1.4|推论 1.4：定量电路下界]] | 固定密度3-SAT的较强判定界 | 存在 $L\in\mathrm E^{\mathrm{NP}}$、$c>0$，无穷多 $n$ 上 $C_L(n)>cn\sqrt{\log n}$ |

这里 $\rho(n)=n(\log\log n)^2/\sqrt{\log n}$。1.2 与 C.2 的原文陈述采用这一较弱指数，而非主定理的更强时间界。

## 理解推论时的四个要点

1. **C.1 给出超线性电路下界。** 原文是类不包含关系，存在一个语言不具有线性规模非均匀电路族。
2. **1.4 的下界针对某个语言，在无穷多输入长度上成立。** 其门模型为任意扇入至多二的布尔门、不受限扇出，计非输入门数。
3. **各推论还使用相应的外部工具。** 1.2还用浓缩不等式和电路编码；1.3的完美匹配用唯一延拓编码；C.1和1.4还要外部算法到电路下界理论。具体证明见各节点页。
4. **跟踪归约后的规模参数。** 次指数时间通常不能穿过任意多项式膨胀的归约而保持原指数参数；各归约分别跟踪完美匹配的 $v+e$、电路下界的语言类与量词，以及局部映射的固定局部度 $d$。
