# 主定理：精确计数与两个时间界

固定整数 $k\ge2$，[[1.1|定理 1.1]] 对具有 $n\ge20$ 个声明变量、$m$ 个子句的 $k$-CNF 给出确定性精确计数算法。一般输入的时间为

$$(n+m)^{O_k(1)}2^{O_k(n\log\log n/\sqrt{\log n})},$$

空间为 $(n+m)^{O_k(1)}$ 位。若另固定密度常数 $D>0$ 且 $m\le Dn$，时间为

$$(n+m)^{O_{k,D}(1)}2^{O_{k,D}(n/\sqrt{\log n})}.$$

精确计数为正当且仅当公式可满足。对于固定宽度，这两个时间界均为次指数，因此主定理否定 ETH。

## 两个密度情形怎样得到

固定密度公式直接编码为具有 $O_{k,D}(n)$ 条边的布尔张量网络，然后调用 [[D.1|张量缩并定理]]。一般密度先用 [[6.3|不交稀疏化]]，再用 [[6.1|初始校验]] 与 [[6.2|贪心选择校验]] 把计数转为稀疏多项式公共零点查询，由 [[D.2|稀疏方程计数]] 实现查询。完整参数代入与空间分析见 [[1.1]]；构造路线见 [[route-b]]。

[[route-a|有理插值路线]] 使用另一计数引擎 [[2.2]]，得到 [[6.4]] 中较弱但仍为次指数的时间界。
