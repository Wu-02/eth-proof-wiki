# 指数时间假设论文证明导航

## 计数问题与主结果

固定整数 $k\ge2$。给定有 $n$ 个声明变量、$m$ 个子句的 $k$-CNF 公式 $F$，目标是精确计算满足赋值数

$$\#F=\bigl|\{x\in\{0,1\}^n:F(x)=1\}\bigr|.$$

声明变量包括没有出现在子句中的变量。计数为正当且仅当公式可满足，因此精确计数也提供 SAT 判定接口。

[[1.1|定理 1.1]] 给出确定性次指数时间、多项式空间算法。对于 $n\ge20$，一般输入的运行时间为 $(n+m)^{O_k(1)}2^{O_k(n\log\log n/\sqrt{\log n})}$；若另固定常数 $D>0$ 且 $m\le Dn$，运行时间为 $(n+m)^{O_{k,D}(1)}2^{O_{k,D}(n/\sqrt{\log n})}$。该节点给出定理的条件和完整证明，分别推导一般输入和线性子句数输入的时间界。

## 两条路线与共用工具

- [[route-a|有理插值路线]]：主要内容包括变量分组与共享线性测量、低次数替代形式、Taylor 系数计算和 Hermite 插值。
- [[shared-algebra|公共代数工具]]：对 $\mathbb F_2$ 系数多项式方程组和整数 $\ell\ge1$，构造一个低总次数整数多项式。在布尔公共零点处，该多项式的值模 $2^\ell$ 等于 1；在其他布尔赋值处，其值模 $2^\ell$ 等于 0。
- [[shared-sat|SAT 稀疏化与奇偶校验]]：将输入 $k$-CNF 的满足赋值集合分解为若干叶公式的满足赋值集合的不交并；叶公式仍为 $k$-CNF，且每个变量的出现次数受限。每个赋值给出一个子句违反指示位向量：被违反的子句对应位为 1，其余位为 0。选择作用于这些向量的一组奇偶校验，使赋值所对应的向量通过全部校验当且仅当该赋值满足叶公式。
- [[route-b|张量缩并路线]]：通过有限精度插值与递归缩并得到主定理的更强时间界。
- [[outputs|主定理]]：固定宽度 CNF 的精确计数、两个密度情形的时间界与多项式空间。

两条计数路线共用 SAT 归约和代数表示，但使用不同的计数引擎。[[6.4|命题 6.4]] 的有理插值界已经是次指数；主定理中更强的两个界由张量缩并路线给出。

## 阅读路线

### 共同起点：对象、目标与记号

先读 [[1.1|主定理]] 的输入、输出和时间空间界，再读 [[foundations-sat-counting|SAT 计数与归约接口]] 中的 ETH 与计数任务；符号约定可查 [[notation|记号与全局约定]]。这里需要区分两个任务：计算 CNF 的满足赋值数，以及计算 $\mathbb F_2$ 系数多项式方程组在布尔赋值域中的公共零点数。后者是校验选择过程所调用的计数子程序。其两种实现分别见 [[2.2|有理插值计数]] 和 [[D.2|张量法计数]]；[[6.2|校验选择]] 说明如何调用该计数接口。

### 路线 A：走通有理插值计数

1. **示例与定义。** 从 [[counting-algorithm-overview|有界出现次数的计数示例]] 开始，再读 [[shared-linear-design|共享线性设计]]，依次了解替代形式、变量组和整数线性测量的定义。
2. **求和与恢复。** 按 [[3.2|固定测量后的分离]]、[[3.3|Taylor 系数恢复]]、[[3.4|通用计数例程]] 阅读，核对各自的输入、输出和资源界。
3. **构造设计。** 从 [[replacement-form-construction|辅助坐标与五步构造]] 进入 [[4.1|低维测量]]、[[4.2|非零条目的支撑限制]]、[[4.3|替代行]]，再读 [[4.5|均衡标记]]、[[4.6|分母与系数界]]、[[4.7|完整构造]]、[[4.8|参数选择]]。
4. **从方程到计数器。** 按 [[5.1|奇偶示性多项式]]、[[B.1|系数与构造成本]]、[[5.2|总阶截断]] 阅读公共代数工具；随后读 [[5.3|给定设计的公共零点计数]] 和 [[exact-arithmetic|精确算术与空间分析]]，最后读 [[2.2|稀疏多项式公共零点计数定理]]。
5. **回到一般 CNF。** 先按 [[A.1|单步分支]]、[[A.2|已标记子句的局部度]]、[[A.3|路径上的插入次数]]、[[6.3|不交稀疏化]] 阅读分支树证明；再读 [[parity-check-reduction|奇偶检验归约]]、[[6.1|初始校验]]、[[6.2|追加校验]]，最后在 [[6.4|一般计数界]] 中核对总时间和空间。

### 路线 B：得到主定理的两个更强时间界

1. **缩并接口。** 先读 [[D.1|张量缩并定理]] 的输入、输出，以及其中的 [[D.1#^subsec-tensor-arithmetic|系数环与精确算术]]。
2. **局部构造与恢复。** 按 [[D.3|端口分包]]、[[D.4|Cauchy 变形的局部整性]]、[[D.5|渐变 Hermite 恢复]] 阅读三个局部结果。
3. **完成缩并证明。** 回到 D.1 中的 [[D.1#^subsec-tensor-modes|模态]]、[[D.1#^subsec-tensor-children|子网络]] 和 [[D.1#^subsec-tensor-cost|递归成本]]。
4. **核对两类 CNF 输入。** 在 [[1.1|主定理]] 中阅读固定密度公式的网络编码；一般密度分支还需 [[shared-sat|SAT 稀疏化与校验]] 和 [[D.2|稀疏方程到网络的编码]]，再回到主定理的总成本分析。
