# 指数时间假设论文证明导航

## 计数问题与主结果

固定整数 $k\ge2$。给定有 $n$ 个声明变量、$m$ 个子句的 $k$-CNF 公式 $F$，目标是精确计算满足赋值数

$$\#F=\bigl|\{x\in\{0,1\}^n:F(x)=1\}\bigr|.$$

声明变量包括没有出现在子句中的变量。计数为正当且仅当公式可满足，因此精确计数也提供 SAT 判定接口。

[[1.1|定理 1.1]] 给出确定性次指数时间、多项式空间算法：一般输入的时间指数为 $O_k(n\log\log n/\sqrt{\log n})$；若另固定常数 $D>0$ 且 $m\le Dn$，则为 $O_{k,D}(n/\sqrt{\log n})$。两者均另乘输入规模的多项式因子。定理的条件、完整证明及两个密度情形的组装都在该节点内。

## 五个数学主题

- [[route-a|有理插值路线]]：固定共享测量后分组求和，由 Taylor 数据与 Hermite 插值恢复计数。
- [[shared-algebra|公共代数工具]]：把二元方程的零值条件写成低总次数的整数表达式。
- [[shared-sat|SAT 稀疏化与奇偶校验]]：把任意公式分成不交的稀疏叶子，再选择足够的校验。
- [[route-b|张量缩并路线]]：通过有限精度插值与递归缩并得到主定理的更强时间界。
- [[outputs|主定理]]：固定宽度 CNF 的精确计数、两个密度情形的时间界与多项式空间。

两条计数路线共用 SAT 归约和代数表示，但使用不同的计数引擎。[[6.4|命题 6.4]] 的有理插值界已经是次指数；主定理中更强的两个界由张量缩并路线给出。
