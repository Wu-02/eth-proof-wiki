# 阅读路线

## 先建立对象与接口

先读 [[1.1|定理 1.1]] 的输入、输出和时间空间界，再读 [[foundations-sat-counting|SAT 计数与相关假设]]；符号约定可查 [[notation]]。需要区分两个任务：对 CNF 公式计数，以及对稀疏二元多项式方程组计算公共零点。先建立后者的算法，再用它选择 SAT 校验行。

## 目标一：走通有理插值计数

1. 从 [[counting-algorithm-overview|有界出现次数的计数示例]] 建立整体图像，再读 [[shared-linear-design|共享线性设计]]，弄清替代行、变量组和共享测量之间的接口。
2. 读 [[3.2|固定测量后的分离]]、[[3.3|Taylor 系数恢复]] 和 [[3.4|通用计数例程]]，理解怎样把所求全局和恢复出来。
3. 从 [[replacement-form-construction|替代形式的构造思路与坐标]] 进入 [[4.1]]、[[4.2]]、[[4.3]]，再经 [[4.5]]、[[4.6]] 到 [[4.7|完整构造]] 与 [[4.8|参数选择]]。
4. 读 [[shared-algebra|奇偶提升与总次数预算]] 及 [[5.3|单次查询位代价]]，同时核对 [[exact-arithmetic|精确算术与空间分析]]；最后读 [[2.2|稀疏多项式公共零点计数定理]]。
5. 用 [[shared-sat|共享 SAT 工具链]] 将计数器接回任意公式，得到 [[6.4|有理插值路线的一般计数界]]。

## 目标二：理解更强的两个时间界

先读 [[D.1|张量网络缩并接口]]，再看 [[1.1|主定理]] 中固定密度公式如何直接编码成网络。随后按 [[D.3|端口分包]]、[[D.4|局部整性]]、[[D.5|渐变 Hermite 恢复]] 的顺序阅读，并回到 D.1 中的模态、子网络和递归分析。最后由 [[D.2|稀疏方程到网络的编码]] 处理一般密度分支；路线关系见 [[route-b]]。
