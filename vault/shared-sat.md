# 共享SAT工具：从不交稀疏化到精确校验选择

路线 A 与路线 B 共用不交稀疏化和校验选择过程。两条路线采用不同的公共零点计数器，并据此选择最终参数。

## 1. 先保持解集，再控制树的规模

[[A.1|引理 A.1]]把一个共享文字集 $H$ 的真假分成互斥的两个子实例。它同时给出两种性质：每个父解恰进一个子节点；每次删除旧子句，都能归因于本轮新增的严格子集。前者保证计数保持，后者用于控制搜索树规模。

[[A.2|引理 A.2]]利用“最小宽度优先、同宽度最大共享集优先”，控制仍在场的已标记子句局部密度。[[A.3|引理 A.3]]结合删除归因和局部度界，把累计插入量写成“存量＋已删除量”，得到 $T_j\le4(3M)^{j-1}n$。于是每条路径短，且插入大量子句的 B 分支罕见；编码这些少数位置即可界定整棵树，而不只是某个叶子的大小。

[[6.3|引理 6.3]]调节 $M$，将上述计数界转化为节点数 $\operatorname{poly}_k(n,\sigma^{-1})2^{\sigma n}$ 与每变量出现次数 $B=O_k([\sigma^{-1}\log(2/\sigma)]^{k-1})$ 的权衡。所有叶子保留原来的 **$n$ 个声明变量**，包括未使用变量；它们的解集两两不交，所以精确相加，无需容斥、近似或变量复制。输入子句数仍记 $m$，某个叶子的子句数记 $m_G\le Bn$，不可混用。

## 2. 把一片叶子的所有子句压成线性数量的校验

对于叶公式 $G$，令 $v_e(x)$ 是子句违反指示多项式：正文字给因子 $1+x_v$，负文字给因子 $x_v$，运算在 $\mathbb F_2$ 上。它的次数至多 $k$、展开后至多 $2^k$ 个单项式。矩阵行对应
$$P_i(x)=\sum_{e:A_{ie}=1}v_e(x)=0.$$
令 $N(A)$ 为通过全部校验的赋值数，$D(A)$ 为其中不满足 $G$ 的赋值数。任何满足赋值都通过，因而 $N(A)=\#G+D(A)$；目标仅是消灭幸存错误数 $D(A)$，不能误把任意中间系统当成等价 SAT 系统。

[[6.1|引理 6.1]]构造至多 $3n$ 行的初始矩阵，每行支撑至多 $D_0$。通过其校验的非零违反向量重量至少 $m_G/P$。因此 [[6.2|引理 6.2]] 的长度 $P$ 随机列表能以至少四分之一概率拒绝每个幸存错误赋值。穷举列表并选择公共零点数最少者，便确定性实现每轮至少四分之一的缩减；$3n$ 轮后错误数为零。

这里 $P=20000B^2\mu^2$、$D_0=320000B^2\mu^3$、$\mu=\lfloor\log_2m_G\rfloor+1$。候选方程至多 $6n$ 个，次数至多 $k$，每式至多 $2^k\max(D_0,P)$ 个单项式，变量数始终是 $n$。

## 3. 最重要的接口：选择器需要计数，但不循环

[[6.2|引理 6.2]]是一个**带公共零点计数调用的选择过程**。它的概率／平均值证明只依赖 [[6.1|引理 6.1]]；实际执行时，每个候选都要调用计数器。原文的两种实现为：

- **路线 A：**[[2.2|定理 2.2]]对任意合格稀疏多项式系统给出精确计数，代入选择器及最终一次查询，进入 [[6.4|命题 6.4]]。
- **路线 B：**[[D.2|引理 D.2]]用张量收缩实现同一接口，代入选择器及最终查询，进入 [[1.1|定理 1.1]]的任意密度结论。

两者都先独立处理“任意合格系统”，不是以“系统已经由 6.2 选好”为前提。候选被淘汰也不影响可计数性。因此，6.2 的校验缩减论证与计数器的实现相互分离，不存在循环调用尚未建立的结论。

## 4. 两条路线如何合并资源预算

固定 $k$，当 $B=(\log n)^{O_k(1)}$ 时，初始化和至多 $3n(2m_G)^P+1$ 次查询只增加 $\exp((\log n)^{O_k(1)})$ 的开销。路线 A 每次查询的指数为 $O_k(n(\log\log n)^2/\sqrt{\log n})$；路线 B 为 $O_k(n\log\log n/\sqrt{\log n})$。这才是“更换计数器改善总上界”的准确位置。

路线 A 在 [[6.4|命题 6.4]]中取 $\sigma=1/s$，其中 $s=\lfloor\sqrt{\lambda}/\nu^2\rfloor$，$\lambda=\lceil\log_2n\rceil$、$\nu=\lceil\log_2\lambda\rceil$；$s<2$ 时穷举。路线 B 在 [[1.1|定理 1.1]]中取 $\sigma=1/\lceil\sqrt\lambda\rceil$。两种选择都令 $B$ 保持多对数，并把叶子数量纳入各自目标指数。树按深度优先遍历，候选和计数器调用依次处理；由于叶解集不交，累计计数不超过 $2^n$，只需 $n+1$ 位。

## 各条依赖的具体作用

- `A.1 → A.3`：将删除次数归因于新增子句的合法性，不是仅传递“解集不交”。
- `A.2 → A.3`：在场标记度界转为在场子句数量上界和每次插入所对应的删除数量上界。
- `A.3 → 6.3`：路径深度与 B 分支次数，进一步得到树大小。
- `A.1 → 6.3`：不交计数保持及每次 B 分支的批量插入，属于直接用途；原图虚线不代表可省略。
- `6.1 → 6.2`：非零违反向量的重量下界。
- `2.2 / D.2 ⇢ 6.2`：表示两种可替换的**计数器实现**，而非选择过程的逻辑前提。
- `6.2 → 6.4 / 1.1` 与 `6.3 → 6.4 / 1.1`：分别提供叶子计数过程与不交稀疏叶子的枚举；不是互相证明。
